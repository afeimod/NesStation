## 一、三国战记3HD（kov3hd / PGM3）启动失败根治

### 根因（本次反编译坐实）

**libpgm3.so 的 `nativeRun` 是同步阻塞调用**：JNI 反汇编
（`Java_com_codegg_afbn_pgm3_Pgm3Activity_nativeRun`，5800 字节）逐段核实——

1. 入口原子交换"运行中"标志（已有会话 → 立即返回 -2）；
2. `freopen` 重定向 stdout/stderr（性能日志或 /dev/null）；
3. 写 interactive.log 头 + `setenv(PGM3_ROM_ZIP / PGM3_ROM_CHD /
   PGM3_MCU_PEER / PGM3_FRAM_SAVE)`；
4. **在调用线程内跑完整场模拟**，直到会话结束（用户退出 / nativeStop）
   才返回 0；-1 = 初始化失败。

参考 APK（afbn）因此把 nativeRun 放进独立线程。其 Pgm3Activity 的
surfaceCreated 回调（反汇编方法 `b(I)V`）的完整顺序是：

```
surfaceCreated → nativeSurface(surface) → resourceProblem 预检(缺文件即中止)
→ mkdir <root>/fram-save → nativeCardConfigure（失败即中止）
→ nativeCheatConfigure → started = true → new Thread(…, "KOV3HD").start()
```

而本项目的 Pgm3Engine.loadRom 把 nativeRun 直接放在 IO 协程里同步调用：

- 整场游戏期间 loadRom 不返回 → isLoaded 恒 false → 前端一直显示加载层
  （用户看到的就是"一直显示解压 chd"的提示）；
- 看门狗在 nativeRun **之后**才启动 —— 此时会话早已结束，帧号=0、状态
  冻结 → 必然触发"核心连续 150s 无任何活动"的误判；
- 即使游戏真的在跑，画面也永远被加载层挡住。

### 修复（Pgm3Engine.kt，对齐参考实现）

1. **工作线程模型**：`Thread("KOV3HD")` 里跑 nativeRun；`started = true`
   在线程 start 前置位（同参考实现）——surface 暂停联动、输入、FPS 在
   会话全程生效；
2. **看门狗改为"会话运行中"监护**：首帧出现（nativeFrameCount>0）即判定
   启动成功并返回，前端撤加载层、画面直接可见；工作线程继续跑模拟直到
   用户退出（nativeStop → nativeRun 返回 → cleanup join）；
3. **线程死亡 = 确定性失败**：nativeRun 提前返回时立刻用返回码 +
   interactive.log 给出真实原因（-2 明确提示"已有会话在运行"）；
4. cleanup() 有界 join(3s) 工作线程，杜绝下一局撞上核心的会话互斥标志；
5. 超时矩阵保持 v60 语义（首帧 300s / 总限 480s / 静默判死 150s）。

涉及文件：
- `app/src/main/java/com/nesstation/app/core/engine/Pgm3Engine.kt`（核心重写）
- `app/src/main/java/com/codegg/afbn/pgm3/Pgm3Activity.kt`（JNI 语义注释修正）

## 二、所有核心摇杆方向的默认映射（按键映射页）

用户反馈：所有核心的按键映射里"摇杆·上/下/左/右"默认都显示"未设置"。

### 修复

- **左摇杆四向**（`*_ls_*`）默认绑定手柄十字键：KeyMapScreen 显示与其它行
  一致的"方向上/下/左/右"（defaultKeyCode = DPAD_UP/DOWN/LEFT/RIGHT）；
  运行时（`resolveKeyStickActionId`）增加默认键回退——无自定义绑定时，
  十字键同时驱动数字方向位与左摇杆模拟轴（十字键手柄/键盘开箱即用摇杆）；
- **右摇杆四向**（`*_rs_*`）默认无键但行内显示"手柄右摇杆轴"（物理右摇杆
  轴本来就直连模拟轴，不再显示令人困惑的"未设置"），仍可自定义绑定；
- 键位监听由 `else-if` 链改为**并行解析**：普通按键位与摇杆方向动作同时
  生效（旧链路下默认绑定的摇杆方向永远轮不到）；4 处监听点全部统一
  （SurfaceView 主路径 + Rebind 路径 + NDS 画布两处）；
- 自定义绑定优先级不变：用户重映射过的动作只认自定义键（并屏蔽其默认键）。

涉及文件：
- `app/src/main/java/com/nesstation/app/ui/settings/KeyMapScreen.kt`
  （PS2/PSP/DC/PSX/3DS/NGC-WII/WiiU/Switch 共 8 核 56 行默认值）
- `app/src/main/java/com/nesstation/app/ui/emulator/EmulatorScreen.kt`
  （内部动作表 + 解析函数 + 4 处键位监听）

## 三、全核心摇杆优化（参考 afbn 的摇杆逻辑）

参考实现 `HardwareInput.getAxisMatch / setAxisPressedState`（反汇编核实）：
模拟轴以**固定阈值 ±0.32 判向** + **状态变化去重**（方向位不变不重复派发）。
本项目多平台需要连续模拟轴，在保留 v59 滞回思想的基础上对齐参考逻辑：

1. **径向死区**：`√(x²+y²)` 整体判定（旧版逐轴方形死区，斜向轻推会突跳）；
2. **线性重缩放**：越界后 `(mag-dz)/(1-dz)` —— 轻推即有渐进输出、满推仍
   归一化 1.0（旧版越界后原样输出，轻推段精度全丢）；
3. **左右杆独立滞回**（旧版共享幅值：一杆在动会抬高另一杆的释放阈值）；
4. **街机（FBNeo/afbn/PGM3）数字摇杆**：这些平台无模拟轴路由（旧版实体
   摇杆完全无效），现按参考实现同款阈值（0.32 触发 / 0.24 释放滞回）把
   左摇杆转成 8 向数字方向位并入 routePadBits 链路 —— 街机搓招/走位
   与参考 APK 手感一致；
5. 帽轴（HAT_X/Y）十字键链路保持不变。

涉及文件：`app/src/main/java/com/nesstation/app/ui/emulator/EmulatorScreen.kt`
（hardwareAnalogListener 重写 + GameSurfaceView 新增 hwStickDirHolder 状态）

## 使用提示

1. 三国战记3HD：kov3hd.zip 与 kov3hd/kov3hd_m105.chd 放同一目录（或直接选
   kov3hd_m105.chd 启动）；首次启动大 CHD 仍需解压时间（提示条会显示核心
   状态与已等待秒数），画面出现即进入游戏；退出游戏请用菜单里的退出，
   勿强杀应用（保证记忆卡/FRAM 落盘）。
2. 摇杆默认映射如被旧版自定义绑定占用，请在 设置 → 按键映射 → 对应核心
   里点该行重新绑定，或"重置当前核心为默认按键"。
