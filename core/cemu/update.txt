【修改版更新说明】

本版本基于官方 Cemu-AZ（SSimco 的 Android 移植版，Cemu 2.x 源码，2026-05 基线）修改，
在官方基础上新增/修复/改进了以下内容：

═══════════════════════════════════════
一、新增功能
═══════════════════════════════════════

1. 运行时即时存档 / 读档（全状态快照）
   - 完整捕获模拟内存、PPC 线程上下文、调度器、SysAllocator 偏移、
     打开的文件句柄位置及可写文件内容等
   - 原地恢复：暂停 → 覆盖内存 → 重建线程调度器 → 继续运行，无需重启游戏
   - 恢复前全量校验文件，失败不会破坏当前模拟状态
   - 覆盖线程、闹钟、消息队列、GPU 异步命令队列、文件系统等状态的保存恢复
   - 支持音频输出（AX）状态随存档一并保存

2. 快速存档槽位（带缩略图）
   - 槽位界面显示截图缩略图，一键快速存取
   - 附带 MLC 存档数据副本作为兜底，进程关闭后仍可恢复
   - 优先尝试原地恢复；失败时自动回退到传统重载方式

3. 金手指（Cheats）支持
   - 内置金手指管理器，解析并应用金手指文件
   - 游戏内金手指对话框 + 原生接口

4. 游戏封面
   - 自动下载游戏封面、本地导入/删除、内存缓存

5. 图形包在线下载
   - 图形包列表内置下载功能

6. 内置资源
   - 打包自带 bundled_graphic_packs.zip 图形包资源
   - 完整简体中文汉化（全新 cemu.po / cemu.mo）

═══════════════════════════════════════
二、修复问题
═══════════════════════════════════════

1. 读档 / 即时存档闪退（多轮修复）
   - 修复读取即时存档闪退
   - 修复读档多次闪退（线程上下文、信号量、GPU 缓存复位等）
   - 修复读档时崩溃导致进程退出

2. 悬浮画面（小窗）修复
   - 修复悬浮画面透明度失效
   - 修复悬浮画面显示问题

3. PSP 相关修复
   - 修复 PSP 相关文件系统（IOSU fsa）与输入问题
   - 相关音频输出（AX）适配修复

4. 构建修复
   - 修复 Android 构建流程（CI/CMake 链接等），确保可正常出包

═══════════════════════════════════════
三、改进与调整
═══════════════════════════════════════

1. 音频输出核心（ax_out）重构与改进，调整音量/设备相关处理

2. Pad / UI 调整
   - 调整 GamePad 位置与显示
   - 悬浮画面（小窗）相关 UI 优化

3. 设置项扩展
   - 新增原生设置接口（NativeSettings），支持更多运行参数

4. 构建流程优化
   - 更新 build_android.yml / build_check.yml，完善自动构建
