【修改版更新说明】

本版本基于官方 Cemu-AZ（SSimco 的 Android 移植版，Cemu 2.x 源码，2026-05 基线）修改，
在官方基础上新增/修复/改进了以下内容：

═══════════════════════════════════════
一、新增功能
═══════════════════════════════════════

1. 运行时即时存档 / 读档（全状态快照）
   - 完整捕获模拟内存、PPC 线程上下文、调度器、SysAllocator 偏移、
     打开的文件句柄位置及可写文件内容等
   - 原地恢复：暂停 → 覆盖内存 → 重建线程调度器 → 继续运行，无需重启游戏
   - 恢复前全量校验文件，失败不会破坏当前模拟状态
   - 覆盖线程、闹钟、消息队列、GPU 异步命令队列、文件系统等状态的保存恢复
   - 支持音频输出（AX）状态随存档一并保存

2. 快速存档槽位（带缩略图）
   - 槽位界面显示截图缩略图，一键快速存取
   - 附带 MLC 存档数据副本作为兜底，进程关闭后仍可恢复
   - 优先尝试原地恢复；失败时自动回退到传统重载方式

3. 金手指（Cheats）支持
   - 内置金手指管理器，解析并应用金手指文件
   - 游戏内金手指对话框 + 原生接口

4. 游戏封面
   - 自动下载游戏封面、本地导入/删除、内存缓存

5. 图形包在线下载
   - 图形包列表内置下载功能

6. 内置资源
   - 打包自带 bundled_graphic_packs.zip 图形包资源
   - 完整简体中文汉化（全新 cemu.po / cemu.mo）

═══════════════════════════════════════

═══════════════════════════════════════
四、R15（NesStation 集成批次 · 2026-10-18）
═══════════════════════════════════════

1. SWKBD 中文输入修复（"wiiu 核心调用输入法没有支持中文输入"）
   - app 契约 NativeSwkbd.kt：黑名单正则（仅允许 ASCII 字母数字与少量
     符号）改为只过滤控制字符 —— 中文/日文/韩文/Emoji 经 Android IME
     提交后不再被整字符删除（Kotlin 层是 IME 中文被吞的唯一根因）；
     maxLength 截断仍按 UTF-16 单元计数（中文一字=1，与核心同口径）
   - C++ NativeSwkbd.cpp：差分与注入从【字节】口径改为【UTF-8 码点】
     口径 —— 删除按码点数注入 BACKSPACE（不再多退格）；注入逐码点
     keyInput；>0xFFFF 码点（Emoji 等）按 UTF-16 拆高低代理对分两次
     注入（formStringBuffer 每格一个 UTF-16 单元，GetInputFormString
     的 16 位转换对代理对天然正确）
   - EmulatorScreen CemuTextInputDialog：keyboardType 显式 Text，
     文案注明支持中文

2. GX2DrawDone 偶发掉帧修复（"gx2draw 不稳定，游戏会偶尔掉帧"）
   - GX2_Event.cpp 档1（滞后等待）：滞后环空槽期（开局前 5 次调用、
     时间戳回卷清环后的 5 次调用）target==0 时原实现完全不等待 →
     游戏线程无界领跑（读盘界面 DrawDone 密集循环最严重），环填满后
     突然全额等待 —— 观感即开局/读图偶发掉帧。改为回退到环内最旧
     非零快照：首调用等自身提交（等效严格等待，仅一次），第 2 次起
     滞后有界，环填满后自动收敛回 lag 档语义
   - vk_accurate_barriers 默认值 true → false（CemuConfig.h/.cpp）：
     与应用 UI 声明的默认档（"关闭 (默认·快)"）对齐；Android 移动端
     每个 barrier 都付现性能代价，社区实测关闭后帧率更稳。首个构建
     的首局不再以 true 跑（"第一次进去特别卡"的一部分）。个别花屏
     游戏可在设置页手动开回 true
